# AGENTS.md

## Project

- Project name: picture-chinese-quest
- Created date: 2026-07-06
- Main goal: 制作可在电脑和手机上玩的看图猜成语、文言文和古诗词闯关游戏
- Owner: 徐锦成
- Discussion language: Chinese
- Tech stack: HTML, CSS, JavaScript

## Working Rules

- 先解释关键思路，再实现。
- 题库必须按年级标注，不能把高年级内容伪装成低年级内容。
- 三个模式都以“图形 + 少量文字 + 符号”组成看图谜题。
- 奖励必须影响提示、得分、连胜或闯关，不能只有装饰作用。
- 修改后检查电脑与手机布局，并实际完成至少一轮答题。
- 保持静态网页结构，不引入必须联网的依赖。

## Important Files

- `index.html`: 游戏页面结构
- `styles.css`: 主题和响应式样式
- `questions.js`: 分年级题库
- `game.js`: 游戏状态与交互
- `MEMORY.md`: 持久项目记忆
