# 生日关卡

- 生日页面可直接访问，作品集生日当天按香港时间显示顶部横幅，次日改为项目卡片。
- 生日琴台优先支持声学钢琴麦克风单音跟弹，电脑键盘和屏幕琴键作为备用。愿望游戏在浏览器内运行。
- 家庭信件、随信照片和影音使用家庭会话，素材与密钥由服务端配置。
- 生日开场优先呈现庆祝仪式。街机厅用游戏史短卡搭配原创关卡，首次过关发星核，高分和奖励沿用本机存档。
- 商店兑换亲子体验券。真实游戏时间、出行和餐饮安排由家人当面约定。
- 背景音乐在用户交互后播放，允许关闭。琴台自动连奏指定四首曲目的短段，末曲后接切蛋糕。
- 游戏史以橙子向导的短对话开场，时代和机型资料带来源，配图是原创示意。许愿 AI 用可比较的本地游戏配置展示设计选择、玩家影响和下一轮修改。
- 分幕旁白及页间动效贯穿开场至谢幕，重播保留本机星核、兑换记录和装扮。吹蜡烛的音量检测留在设备，麦克风授权随操作释放。
- 2026-11-25: 引导弹出时先隐藏顶部导航和 HUD，旁白结束后再揭开章节；场景切换加入明显的翻页纸面动效。蛋糕按 3D 分层布置，吹灭后逐根拔蜡烛再切；琴键上方显示落音，按键时散成余烬。
- 生日蛋糕复用 Blow Candles 的环境噪声与吹气检测，以及 polygon-splitter 的两刀分块。保留十二根蜡烛、按住吹气和按钮切片，手势以蛋糕表面为坐标，切出的蛋糕露出夹层后滑到盘中。
- 蛋糕默认使用 Three.js 立体模型，支持橙瓣巧克力、草莓鲜奶油、经典香草、浓巧克力四款，记住本机选择。换款保留蜡烛状态，第一刀完成后锁定款式。立体糖霜和草莓造型改自 Blow Candles，分层切片改自 Birthday Bloom；WebGL 不可用时使用平面备用渲染。

- 生日琴台致敬橙子的 Boss 钢琴训练营，复用 Yamaha C5 采样、单音识别和《机甲序曲》。四首生日关曲目按原流程转入切蛋糕。

- 2026-11-26：生日琴台主线从《生日快乐》到《午夜追击》，支持分手和双手、BPM 与按拍号重音的节拍器。麦克风跟弹时节拍器只闪光，同组多音逐个确认。原生日曲目保留为加演，旧星核不重复发放。

- 成长日志以作品记录为依据，按已知时间或作品展现的创作技能回看。奖章表扬具体设计选择，每件作品配可选的小实验。真实对话沿用家庭会话配置。
- 幕前提示只显示一个居中的主按钮。点击提示框外或按 Esc 同样进入下一幕。
- 右下角「版本与致谢」用电影片尾的形式呈现。版本里程碑和致谢维护在 `content/copy.json`，字幕可暂停、重播和手动滚动。系统开启减少动态效果时，默认手动浏览。
- 生日开场点亮后直接进入第一幕旁白。幕间隐藏导航时保留占位，翻页约 0.6 秒。烟花开关同时控制背景和庆祝烟花，遵循系统减少动态效果设置。
- 琴台电脑快捷键在琴键区聚焦时生效。蛋糕麦克风等待授权时可取消，迟到的授权立即释放音轨。吹灭后可逐根拔蜡烛，也可收起剩余蜡烛，再用手势或按钮切片。
- 切蛋糕默认引导从中心向外缘划。判定以连起中心附近和外缘为准，支持反向与划出外缘。
- 3D 蛋糕的浏览器 ES modules 在 Vercel 函数包中使用 .js.txt 扩展名保存原始内容，由生日 API 以 JavaScript MIME 类型提供原有 .js URL。
- 访客祝福由家长用独立口令审核后公开，预览和生产各自保存留言。
- 2026-11-26：街机、愿望工作台和家书试行固定舞台。切换玩法或打开试玩时在幕内切换，长信按内容分页，空间不足时保留内容区滚动。先用这三幕验证玩法、阅读和输入，再决定是否推广。
- 试玩优先给画面留空间。开局进入独立游戏舱，宽屏侧栏承载说明和操作，竖屏控件在下方，浏览器全屏由网页右上角控制，进出试玩和切幕保留全屏状态。
- 所有章节共用单屏舞台。浏览类内容优先按类别和数量陈列，长内容在当前幕内连续滚动，演奏、切蛋糕和试玩优先留操作空间，极小窗口可以滚动到其余操作。
- 2026-11-26：幕间切幕优先使用原生 View Transitions（书页 3D 翻折与蛋糕/终幕柔光破晓），不支持或开启减少动态效果时回退 `.page-turn`；离开蛋糕幕先 `suspend()` 释麦、切幕时再销毁 WebGL。3D 蛋糕在进幕前预取模块并使用内置 `PMREMGenerator` 程序化环境反射，保持默认直出 sRGB 不开 ACES。背景烟花按高分屏与像素预算缩放，街机/非节拍愿望游戏舱通过 `pauseSky` 仅停烟花不静音背景音乐；翻页和礼物微音效仅在背景音乐开启时轻声伴随。
- 2026-11-27：新增全屏共享 WebGL2 3D 舞台模块 `stage-3d.js.txt`（经 `api/mission.js` 白名单以 `/birthday/stage-3d.js` 提供），首帧渲染后挂 `body.cinema-ready` 并接管 `#sky` 背景归属权，烟花仅在开场/蛋糕/商店/谢幕触发。幕间切幕改为单时钟相机推轨，进蛋糕幕与打开游戏舱时暂停 `#world-3d` 渲染循环、离幕析构蛋糕后再恢复；琴台离幕支持 `suspend()` 保留尾音同时停麦停节拍器。`?cinema=0`、WebGL2 不可用、上下文丢失或 `prefers-reduced-motion` 自动无损回退既有 2D 舞台。
- 2026-11-27（12.2.0）：转场通过 `body.dataset.chapter` 与 `guide.dataset.actKey` 驱动 10 幕独立主题色与拉焦动效；`#scene-guide` 在 2D/3D 下均居中聚焦、背景模糊压暗并在 3 秒倒计时后自动跳转（不覆盖 `cake()` 内的 `.scene-guide` 弹窗）。游戏史改为全宽 6 年代横向滑轨与 3 秒自动轮播。`arcade.js` 使用 `Map<key, Set<pointerId>>` 处理大尺寸移动端多点触控。琴台升级全曲双手曲库（含《星核终章 · 双手狂想》）、三档难度（默认 750ms/麦克风 1600ms 双手合奏窗口 + 实时落键评级）及双区键盘映射（左手 `Z–M`/`S–J` 配合 `,`/`.` 移调，右手 `Q–P`/`2–0` 配合 `[`/`]` 移调），许愿工作台展示 `wishAiConfigured` 状态并记录最近 8 条原型到 `save.wishes`。

- 2026-11-28（12.3.0）：各幕通过 `markActReady` 上报完成，切幕清空状态，小八使用 `hachi/` 的四张透明 WebP。钢琴主线继续使用编号存档和既有星核、蜡烛计算，曲库与加演通关独立记录在 `pianoExtraCompleted`，家庭旧版 `phrases` 覆盖仍可使用。
