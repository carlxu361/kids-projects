# 小八向导素材

四张透明 WebP 均来自 [Chiikawa Wallpaper 的小八 PNG 素材页](https://chiikawawallpaper.com/png/hachiware)。素材裁去透明边缘后存放在项目的 `hachi/` 目录，页面通过 `/birthday/hachi/` 加载。

| 文件 | 用途 |
| --- | --- |
| `guide.webp` | 顶部头像、日常提示与通用报幕 |
| `cheer.webp` | 街机、游戏史与钢琴完成后的欢呼 |
| `star.webp` | 作品、蛋糕、来信与奖励提示 |
| `wave.webp` | 开场报幕与谢幕 |
