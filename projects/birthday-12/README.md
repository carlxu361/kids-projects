# 生日关卡（当前版本：12.3.0）

## 本地预览

在包含 `package.json` 的 `kids-projects` 仓库根目录用 Node.js 22 运行。这个工作区里，从外层 `stevesBirth12` 先执行 `cd kids-projects`。

```sh
npm run build
BIRTHDAY_DATE=2099-11-28 BIRTHDAY_PREVIEW_KEY=local-preview-only npm run birthday:preview
```

打开 http://127.0.0.1:8787 检查 19 张卡片。普通访客可直接打开 http://127.0.0.1:8787/birthday。需要模拟提前授权时，打开 http://127.0.0.1:8787/birthday?preview=local-preview-only。将日期设为香港当天可验证首页横幅，设成过去日期可验证首页显示第 20 张卡。上面的密钥只用于本地。

## 单屏舞台

开场和全部章节使用同一个单屏舞台。游戏史按年代切换，同年代展品同时陈列。奖章、试玩和兑换品按数量排布，信封居中。成长日志按类别浏览，家书与谢幕祝福可以连续阅读。钢琴和蛋糕优先给键盘与蛋糕留空间，宽屏操作区在侧边，手机竖屏上下排列。街机试玩铺满可见窗口。右上角控制整页全屏，切幕和退出试玩会保留该状态。窗口过矮、文字放大或文字较长时，当前内容区可以滚动。

本地验收覆盖桌面、手机窄屏和横屏。检查游戏史与奖章陈列、琴键和设置、吹蜡烛与切蛋糕、愿望试玩和返回、家书阅读、商店兑换券与谢幕。用手机实机补验地址栏、软键盘和麦克风权限。开启减少动态效果后，确认切幕和信纸打开不会播放位移动画。

## Vercel 部署

先在本地或受保护的预览环境验收。生产上线由爸爸确认后，将本分支的改动合入现有作品集项目的部署分支。保留当前的域名及项目 Root Directory。项目使用 Node.js 22、Other 框架、`node scripts/build-portfolio.mjs` 构建及 `dist` 输出，由仓库根的 `vercel.json` 声明。若 Dashboard 有旧的构建或输出覆盖设置，预览时核对。静态构建只复制首页、卡片脚本、现有编号作品。生日内容通过 Functions 提供，不需要复制到静态目录或添加 `.publish`。

| 环境变量 | 用途 |
| --- | --- |
| `BIRTHDAY_DATE` | 默认 `2026-11-28`，香港时间当天展示首页横幅，次日展示项目卡片 |
| `BIRTHDAY_PREVIEW_KEY` | 爸爸用来提前预览的随机密钥 |
| `BIRTHDAY_FAMILY_KEY` | 生日后查看家庭私密素材的独立随机口令 |
| `BIRTHDAY_SESSION_SECRET` | 建议设置随机会话签名密钥，缺省使用预览密钥 |
| `BIRTHDAY_CHATLOG_JSON`、`BIRTHDAY_FAMILY_JSON` | 家庭可访问的真实日志和留言 |
| `BIRTHDAY_MEDIA_BASE`、`BIRTHDAY_MEDIA_TOKEN`、`BIRTHDAY_MEDIA_JSON` | 私密文件源 HTTPS 基础地址、Bearer 凭据和允许访问的文件映射 |
| `BIRTHDAY_SONGS_JSON` | 可选家庭会话短谱覆盖，结构与 `content/songs.json` 相同 |
| `AI_API_BASE`、`AI_API_KEY`、`AI_MODEL` | 许愿工作台的 OpenAI 兼容服务地址、服务端密钥与可选模型 ID（`AI_MODEL` 缺省默认使用 `gpt-4o-mini`；未配置地址或密钥时前端自动切回本地示例模式） |
| `WISH_REQUIRE_SESSION` | 可选，`1` / `true` 时强制要求家庭或预览会话才能调用许愿 AI 接口；不配或设为关闭时允许访客体验并受限流保护 |
| `BIRTHDAY_REDIS_URL`、`BIRTHDAY_REDIS_TOKEN` | 服务端 Redis REST 地址和写入令牌，供祝福存储和愿望工作台限流（未配置 Redis 时许愿接口降级为进程内内存限流） |
| `BIRTHDAY_MODERATOR_KEY` | 独立家长审核口令，至少 8 个字符，建议使用自己记得住、他人难猜的口令 |
| `AI_MINUTE_LIMIT`、`AI_DAILY_LIMIT`、`AI_TOTAL_LIMIT` | 可选，默认每分钟 3 次、每日 20 次、活动 60 次 |
| `BIRTHDAY_CREDITS_JSON` | 可选真实制作统计，以字段名覆盖彩蛋面板的样稿 |

预览链接为 `/birthday?preview=预览密钥`。成功后服务端写入签名会话 Cookie 并重定向到 `/birthday`，会话四小时过期。预览链接本身相当于口令，可能被浏览器或接入层记录，只给爸爸使用。生日后可在船员页输入独立家庭口令。所有私密变量只配置在服务端。真实内容应在测试通过后填入生产环境。

## 替换内容

- `content/chatlog.json` 是日志样稿，按相同结构把真实 JSON 配入服务端。只选已授权的段落，并填写每条真实日期、对应作品链接和爸爸的旁白。对话总数与首日需有原始记录。
- 琴台「双手曲库」可按分类浏览、选曲和试听。含左手音符的曲目可切换双手、右手或左手。`BIRTHDAY_SONGS_JSON` 接受双手 `left` / `right` 小节数组和旧版 `phrases` 单手谱。生日主线前四首跟弹后自动换曲，末曲结束时可继续选曲或前往吹蜡烛。
- `content/family/index.json` 是五人样稿。家庭真实 JSON 保留相同的五个 ID 和顺序。需要音视频时，在成员项加 `"media":"mom.m4a"`，并在媒体映射填 `{"mom.m4a":"private-file.m4a"}`。私密源要求凭据，并支持 Range 请求。随信照片可加 `"photo":"mom.webp"` 及可选描述 `photoAlt`，再把图片加入同一媒体映射。支持 WebP、JPEG 和 PNG。建议压缩短视频为 H.264/AAC MP4。
- `content/copy.json` 可调整关卡文案和商店。样稿是新写的示例，爸爸可以换成自己会对橙子说的话。小八向导使用 `hachi/` 的四张透明图，来源与用途见 [素材说明](content/hachi/README.md)。

## 发布前彩排

- 从普通浏览器核对生日前首页显示 19 张卡，`/birthday/card` 返回 404，直达关卡和公共素材可加载。
- 当天核对首页顶部横幅，次日核对第 20 张卡。普通会话没有真实日志和家庭媒体。
- Chrome 与 Safari 用键盘点亮 12 根蜡烛，验证自动换曲与切蛋糕，断网后继续玩已打开页面的愿望关，并检查家庭口令、图文来信、媒体播放、礼物与彩蛋。
- 在授权的预览环境验证真实媒体源和浏览器控制台。

## 生日街机厅

开场点击会启用合成生日背景音乐和三轮烟花，页首可分别关闭音乐和动态烟花。琴台及打开家书时会暂停背景音乐。开场主视觉为原创生成的 WebP。舞台参考了 [Birthday Bloom](https://github.com/naborajs/birthday-bloom) 的蛋糕与烟花节拍，以及 [Afterglow](https://github.com/bayojuvikas/afterglow-v2) 的声音和庆祝转场。与 [Google 19 周年互动 Doodle](https://doodles.google/doodle/googles-19th-birthday/) 一样，生日入口后可以立即挑游戏。

三款街机为本项目编写。历史节点分别引用 The Strong 的 [Pong](https://www.museumofplay.org/games/pong/)、[Space Invaders](https://www.museumofplay.org/games/space-invaders/) 和 [Tetris 名人堂记录](https://www.museumofplay.org/blog/the-first-class-of-the-world-video-game-hall-of-fame/)。可用键盘、屏幕按钮或游戏支持时用指针控制。每款首通得 2 星核，最高分留在本机。兑换价格与券面可编辑 `content/copy.json` 中的 `shop`。

街机厅时间轴以占满视口宽度的 60 年横向节点展开（1970s–2020s），每版停留 3 秒自动平滑滚动到下一年代，也可暂停、点击节点直跳或在手机端左右滑动切换。走到 2020s 时停止，可点「重播时间轴」从头开始。资料来源随各机型附上。街机 3 款与许愿关 3 款游戏全部通过响应式大触控面板适配手机竖屏与横屏，支持双手多点同时按住方向键与发射键。

时间轴配图是辨识机型特征的原创插画，随各卡的 `art` 命名，放在 `machines/`。生日愿望工作台会在页面上方提示 AI 接口就绪或本地示例模式，生成的原型自动保存最近 8 条到本机存档方便回看与试玩。模型只返回受校验的玩法配置与简短设计理由，客户端用三个本地引擎运行原型。AI 未配置或暂时失败时，仍可打开两版示例和三个预制原型。服务端仅向模型发送当前输入及上一版游戏配置，发起生成会扣一次限额。

## 幕间引导与兑换券

点亮派对后直接显示第一幕旁白。之后依次是游戏史、经典试玩、橙子的作品、钢琴、吹蜡烛与切蛋糕、许愿、来信、兑换和谢幕。每幕开始前会居中聚焦显示带本幕主题色的旁白弹窗与背景模糊压暗，按钮自带 3 秒倒计时自动进入，也可点击或按 Esc 跳过。章节按钮可回看。换装在后续旁白、顶部向导和助手里显示。各幕完成后下一步按钮会亮起，小八在按钮上方提示。弹窗、游戏舱及紧凑键盘模式会收起提示，点顶部头像也可以召唤小八。

吹蜡烛仅在点击麦克风按钮后申请权限，等待时可取消。吹气使用实时音量检测，音频留在设备。吹灭或离开蛋糕页会释放音频流。可按住屏幕上的「吹气」代替。蜡烛熄灭后可逐根拔下，也可一次收起剩余蜡烛。用鼠标或触屏从中心光圈向外缘划两刀。反向划和划出外缘也有效，还可以点「用按钮切一块」。

星核、体验券、向导装扮和当前章节保存在同一地址下的同一浏览器。刷新和重播保留兑换结果。兑换后可下载文字券，换设备时可拿下载的券与家人确认。下载券不会在另一台设备恢复游戏余额。真实朋友来信可以和家庭素材一起填写，放在爸爸来信之前。

### 生日琴台

《生日快乐 · 双手华尔兹》《月下回声》《机甲序曲》《午夜追击》《星核终章 · 双手狂想》五首主线曲目全程包含左右手配合，提供「标准 · 逐步跟弹」「进阶 · 双手合奏」（默认，需在同步窗口内双手配合按下）与「大师 · 实时落键」（3 拍倒数后判定 `PERFECT`/`GOOD`/`MISS` 并给出 S/A/B 评级）三档难度。每首可切换双手、左手或右手，可调整 BPM 和开启节拍器。

使用真实钢琴时，一次弹一个音。网页琴键支持鼠标、手机多点触控双手同弹与电脑双区键盘：聚焦琴键区后，左手低音区使用 `Z X C V B N M` 与黑键 `S D G H J`（按 `,` / `.` 移调），右手旋律区使用 `Q W E R T Y U I O P` 与黑键 `2 3 5 6 7 9 0`（按 `[` / `]` 移调），中央 C4 带有分界线引导，选曲时自动对齐左手主音区。完成主线曲目收集星核（最多点亮 12 根蜡烛），旧曲可在「加演」中选择。

琴声使用 Alexander Holm 的 Salamander Grand Piano，依照 CC BY 3.0 使用。采样、署名和双手示范复用作品墙训练营资源。

## 访客祝福

访客可从庆祝页谢幕或页脚打开祝福窗口。昵称和祝福进入 Redis 待审队列。家长打开窗口内的「家长审核」并输入审核口令，可批准公开或拒绝。预览与生产各自使用独立队列，审核口令与家庭素材口令分开配置。祝福窗口随归档后的项目一并保留。

审核口令每个来源 IP 每天最多输错 5 次，按香港时间零点重置。更新 Vercel 审核口令后需重新部署对应环境。
