# Space Hideout

原创桌面网页 Hide n Seek 多人游戏。当前版本是彻底重建后的阶段 1 工程骨架。

## 当前范围

已完成：

- pnpm workspace
- TypeScript
- ESLint
- Prettier
- Vite + Phaser 3 客户端
- Express + Socket.IO 服务器
- 共享类型包
- HTTP 健康检查
- 客户端连接服务器
- AI 决策地基：BOT 命名、船员/猎手有限状态机、基础效用评分
- 开局准备舱：原创猎手信号播报，按“开始躲藏”后才启动 AI 和倒计时
- 作品集内直接运行的线上试玩版（准备舱、外观、AI 状态和 Phaser 动画）
- 可操作纵切试玩：2600 × 1600 原创双层轨道设施、WASD 移动、Shift 短冲、墙体碰撞、3 个可修复终端、猎手巡逻和危险计量表
- 设施路线：三组有限次跃迁管、三组双向梯子、两条单向滑索；梯子和滑索有锁定移动动画
- AI：猎手会巡逻、视线追击和搜索最后目击点；船员会分工修终端、遇险撤离，并会用跃迁管
- 非血腥回合失败表现：能量失效角色标记，不使用尸体或现有游戏的击杀动画素材
- 装扮扩展：8 种颜色、6 种帽子、3 种面罩、4 种背包、5 种表情动作，选择同步到地图角色
- `/Users/xjc/Developer/games/启动 Space Hideout.command` 双击启动器
- Vitest
- Playwright
- 架构文档

## 安装

```bash
pnpm install
```

## 启动

```bash
pnpm dev
```

默认地址：

- Client: http://127.0.0.1:5173
- Server: http://127.0.0.1:3001
- Health: http://127.0.0.1:3001/health

也可以双击：

```text
/Users/xjc/Developer/games/启动 Space Hideout.command
```

这个启动器会进入项目目录，必要时安装依赖，启动前后端，并打开客户端网址。

## 在线试玩

作品集会把客户端打包成不依赖服务器的试玩版，访问下面的页面即可直接载入：

<https://xxby.carlxu.cn/11-Space%20Hideout/>

试玩版用于展示原创外观、AI 决策状态、准备舱和 Phaser 动画；真正的多人房间需要后续部署支持 Socket.IO 长连接的服务器。

试玩版里的移动、碰撞、终端和设施路线是客户端纵切，用来验证游戏手感和画面；正式多人对局会改为服务器校验最终位置、任务结果与设施使用。

试玩地图坚持原创：可保留“环形路线、中央连接、上下层捷径”这类通用设计思想，但不复刻已有游戏的飞船轮廓、房间名或路线布局。

## 核心规则

- 每局固定一名猎手。
- 公开房间只能随机选择猎手。
- 船员完成任务只缩短普通躲藏时间，不直接胜利。
- 普通 Hide 结束后进入 Final Hide。
- Final Hide 中任务关闭，猎手获得加速、Ping 和 Seek 地图。
- 游戏中不存在会议、报告、讨论、投票和放逐。
