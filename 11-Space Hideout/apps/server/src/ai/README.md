# AI

This folder contains the first AI foundation for the Hide n Seek rebuild.

Current scope:

- BOT name generation with the required `BOT-` prefix
- finite-state intent decisions for crewmates and the hunter
- personality-sensitive escape thresholds
- tests that guard against vents for the hunter and task goals during Final Hide

Not implemented yet:

- pathfinding
- live room integration
- movement commands
- task execution sessions
- AI fill after matchmaking timeout
