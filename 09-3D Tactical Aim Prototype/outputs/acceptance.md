# Prototype 07 验收说明

更新时间：2026-07-12

## 结论

Prototype 07 已把用户反馈中的核心玩法问题改成可验证规则：爆能器、买枪期、AI、静步、小地图、设置、血量、掉枪、出生点、地图大小、枪模、小队战术路线和队友交战都已有代码实现与回归检查。

项目不会直接复制《无畏契约》的地图、英雄、枪械名称/数值、美术、音效或UI。当前实现是原创的战术攻防原型，学习同类玩法结构，而不是使用专有内容。

## 验证命令

```bash
node --check game.js
node --check server.js
node --check checks.mjs
node checks.mjs
```

当前 `node checks.mjs` 通过 37 项玩法回归检查。

## 已覆盖反馈

- 爆能器部署不了：部署/拆除使用地面距离 `flatDistance`，不是玩家眼睛高度的3D距离。
- 买枪能关UI并移动：买枪期 `updateMovement` 直接返回，隐藏买枪UI也不能移动。
- 买枪期能射击：鼠标按下和 `shoot()` 都要求处于战斗阶段。
- 开局就部署爆能器：回合开始 `coreState` 固定为 `idle`。
- 路上放枪：静态路边枪已禁用，只保留买枪和击杀掉枪。
- 队友只会冲/没用：队友有带包、B点突破、控中、侧翼/回防等短角色，并可延迟代拿爆能器去安装。
- 不是 5v5：敌人现在会在玩家和可见队友之间选择目标，队友能被击倒并真实减少己方人数。
- AI卡墙：AI直走受阻会侧移，卡住超过阈值会跳路线点，并通过队形避让减少队友挤在一起。
- AI路线太直：敌我双方使用命名战术路线绕过主要墙体和入口，而不是只朝目标点直线走。
- 静步没用：敌人检测会看朝向、视线和静步状态；不在正面且静步时不会轻易锁定。
- 小地图：按 `X` 全屏，显示队友和爆能器，不显示敌人。
- 小地图标记：点击小地图会在3D地图生成竖直光柱。
- 敌人出生点在外面：双方出生点放到地图深处基地。
- 地图太小/长方形/掩体散：地图边界扩大，使用非长方形地面和通道/点位结构。
- 守护者血量超过100：守护者治疗上限固定为100。
- 设置bug：设置/鼠标锁有防抖，回合切换、回主页、关闭设置会清理输入、射击和开镜状态。
- 枪械模型奇怪：第一人称枪模拆分为枪身、握把、枪管、枪口、弹匣等部件。
- 切刀移速：近战武器提供移动速度加成。
- 部署动画/不能开枪/可取消：部署中禁止开枪，松开会回退部署进度。
- 敌方随便部署：守方视角下，只有敌方带包者进入点内才会安装爆能器。
- 本地服务器：`server.js` 提供 `/api/status`，状态为10人本地战术服务器。
- 版权安全： shipped 游戏文件不含 `无畏契约` 或 `Valorant` 专有名称。
- 预览服务：`node server.js` 可启动本地预览，`/` 返回 `200 OK`，`/api/status` 返回本地10人服务器状态。
