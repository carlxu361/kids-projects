# Asset gap list

P1 deliberately uses procedural primitives. These gaps must be resolved with a clear source and license before a public high-quality release.

| Asset group | Needed for | Current state | Acceptance notes |
| --- | --- | --- | --- |
| Main castle GLB | final hall and towers | PLACEHOLDER procedural geometry | author-created or commercially licensed with redistribution rights |
| Stone / plaster / wood PBR set | courtyard and corridor | PLACEHOLDER colors and roughness | include albedo, normal, roughness, AO license and texel-density notes |
| Character model and animations | player and NPCs | PLACEHOLDER primitives | include idle, walk, run, jump, cast, hit, crouch, prone |
| Wand model | first-person hand and spells | PLACEHOLDER procedural wand | must have first-person and world model variants |
| Torch flame and smoke | environmental light | PLACEHOLDER shader primitives | final shader must have quality tiers and cleanup |
| Ambient / spatial audio | courtyard atmosphere and spell feedback | not included | source, loop permission, attribution, and format recorded |
| HDRI / sky | final lighting | procedural sky and fog | license plus mobile fallback |
| Vegetation meshes | wind-driven courtyard detail | PLACEHOLDER instanced geometry | source and atlas license recorded |
| NPC / enemy models | vertical slice | not included | animation retargeting and silhouette review |

The three requested references remain research-only. Their asset license status is documented in `docs/license-inventory.md`.
